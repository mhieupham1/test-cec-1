# ダッシュボード機能 (Dashboard Feature)

## 概要
ログイン後のメイン画面。ユーザーの統計情報とアクティビティを表示する。

## 機能要件

### 表示項目
- ユーザー名とアバター
- 本日のアクティビティ数
- 週間レポートサマリー
- 最近のプロジェクト一覧（最大5件）
- 通知バッジ

### データ取得
- API: `GET /api/v1/dashboard`
- レスポンス形式: JSON
- キャッシュ: 5分間

### 画面レイアウト
```
+----------------------------------+
| Header (ユーザー名 / 通知)        |
+----------------------------------+
| 統計カード  | 統計カード | 統計カード |
+----------------------------------+
| 週間レポートグラフ                 |
+----------------------------------+
| 最近のプロジェクト一覧             |
+----------------------------------+
```

### 非機能要件
- 初期表示: 2秒以内
- レスポンシブ対応（PC/タブレット/スマホ）
- ダークモード対応
